## SkipIntroVideo Description
SkipIntroVideo adds a native toggle to Valheim's <b>Settings > Gameplay</b> panel.</br>
Use it to choose whether Valheim plays the startup video when the game opens.</br>
When disabled, the game opens directly at the main menu.</br>
The mod only affects the startup video; new-world cinematics, dreams and credits remain unchanged.</br>



<details>
<summary><b>MANUAL INSTALL</b> (<i>click to expand</i>)</summary>
</br>
• Download the latest copy of Bepinex per author's instructions.</br>
• Place the SkipIntroVideo.dll inside of the "Bepinex\plugins\" folder.</br>
• This is a client-side mod. It is not required on dedicated servers or by other players.</br>
</details>

<details>
<summary><b>HOW TO USE</b> (<i>click to expand</i>)</summary>
</br>
• Start Valheim and open <b>Settings</b>.</br>
• Select the <b>Gameplay</b> tab.</br>
• Enable or disable <b>Show startup video</b>.</br>
• Press <b>OK</b>, then restart Valheim for the choice to apply at startup.</br>
</details>

<details>
<summary><b>NATIVE LANGUAGE SUPPORT</b> (<i>click to expand</i>)</summary>
</br>
• The option label and hover tooltip support every official Valheim language.</br>
• Chinese (Simplified and Traditional), Czech, Danish, Dutch, English, Finnish, French, German, Greek, Hungarian and Italian.</br>
• Japanese, Korean, Norwegian, Polish, Portuguese (Brazil and European), Russian, Slovak, Spanish, Swedish, Turkish and Ukrainian.</br>
• The text updates automatically when the language is changed in Valheim.</br>
</details>
